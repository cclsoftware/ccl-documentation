enum CCL::ParameterFlags

Overview

Parameter flags. More…

#include <paramtypes.h>

enum ParameterFlags
{
    kParamBehaviorSignalFirst  = 1 < <1,
    kParamBehaviorSignalAlways = 1 < <2,
    kParamBehaviorBipolar      = 1 < <3,
    kParamBehaviorReverse      = 1 < <4,
    kParamBehaviorOutOfRange   = 1 < <5,
    kParamBehaviorWrapAround   = 1 < <6,
    kParamSemanticStorable     = 1 < <7,
    kParamSemanticListValue    = 1 < <8,
    kParamSemanticGroupable    = 1 < <9,
    kParamSemanticPublic       = 1 < <10,
    kParamSemanticMutable      = 1 < <11,
    kParamSemanticReadOnly     = 1 < <12,
    kParamUserFlag1            = 1 < <13,
    kParamUserFlag2            = 1 < <14,
    kParamUserFlag3            = 1 < <15,
    kLastParameterFlag         = 15,
};

Detailed Documentation

Parameter flags.

Enum Values

kParamBehaviorSignalFirst

parameter signals with old and with new value

kParamBehaviorSignalAlways

parameter signals even if current value is set again

kParamBehaviorBipolar

parameter is bipolar, the center is defined by (max-min)/2

kParamBehaviorReverse

parameter is reverse, display should be upside down

kParamBehaviorOutOfRange

parameter value is out of range

kParamBehaviorWrapAround

parameter increment/decrement does not stop at min/max

kParamSemanticStorable

parameter is storable

kParamSemanticListValue

parameter stores selected list value instead of list index

kParamSemanticGroupable

parameter can be grouped

kParamSemanticPublic

parameter is public

kParamSemanticMutable

parameter is mutable (min/max or list entries can change)

kParamSemanticReadOnly

parameter is used for display purposes only, no editing

kParamUserFlag1

usage-specific
