Detailed Documentation

GUI-side audio meter ballistics: turns a raw, undecayed (linear) AudioMeterData snapshot into smoothly-falling peak, RMS and peak hold levels in dB plus a held clip state.

RMS, clip and peak hold are each individually enabled/disabled (off by default).

Fields

static constexpr float kDefaultPeakDecayRate = 20.f

dB/sec, classic peak-meter fall rate

static constexpr TSeconds kDefaultRMSSmoothingTime = 0.2

one-pole, much lighter than peak hold

static constexpr TSeconds kInfiniteHold = -1.

never auto-release; call resetHolds () to clear

Methods

bool update(const AudioMeterData& rawData, TSeconds elapsedSeconds)

Feed one freshly-read raw snapshot plus real elapsed time since the previous call.

Returns true if any channel’s peak/RMS/clip/peak-hold state changed as a result.

bool resetHolds()

Clear both clip-hold and peak-hold state back to silence/off.

Does not affect live peak/RMS.

uint32 getClipState() const

bit field, one bit per channel
