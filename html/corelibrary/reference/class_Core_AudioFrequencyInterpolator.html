class Core::AudioFrequencyInterpolator

Overview

Logarithmic (octave-linear) conversion: value = min * (max/min)^normalized. More…

#include <coreaudiointerpolator.h>

class AudioFrequencyInterpolator: public Core::Interpolator
{
public:
    // fields

    static constexpr float kDefaultMin = 20.f;
    static constexpr float kDefaultMax = 20000.f;

    // construction

    AudioFrequencyInterpolator(
        float minRange = kDefaultMin,
        float maxRange = kDefaultMax
    );

    // methods

    virtual void setRange(float minRange, float maxRange, float midRange = -1.f);
    virtual float normalizedToRange(float normalized) const;
    virtual float rangeToNormalized(float value) const;
};

Detailed Documentation

Logarithmic (octave-linear) conversion: value = min * (max/min)^normalized.

Requires 0 < minRange < maxRange; midRange is ignored.

Reference: https://www.musicdsp.org/en/latest/Other/87-exponential-parameter-mapping.html
