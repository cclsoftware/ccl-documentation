struct Core::AudioMeterData

Overview

Per-channel VU meter snapshot: peak/RMS levels (linear) and a clip bit field. More…

#include <coreaudiometerdata.h>

struct AudioMeterData
{
    // fields

    int byteSize = sizeof(AudioMeterData);
    int numChannels = 0;
    float* peakLevels = nullptr;
    float* rmsLevels = nullptr;
    uint32 clipState = 0;

    // construction

    AudioMeterData(int numChannels = 0);
};

// direct descendants

template <int kMaxChannels>
struct StaticAudioMeterData;

Detailed Documentation

Per-channel VU meter snapshot: peak/RMS levels (linear) and a clip bit field.

Fields

int byteSize = sizeof(AudioMeterData)

size of this struct in bytes

float* peakLevels = nullptr

linear, one entry per channel

float* rmsLevels = nullptr

linear, one entry per channel

uint32 clipState = 0

bit field, one bit per channel (max. 32 channels)
